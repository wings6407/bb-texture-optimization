# 贴图优化决策与尺度

## 判断能否达到目标

2048×2048 到 128×128：单边缩小 16 倍，总像素缩小 256 倍。RGBA8 且不含 mipmap 时，理论纹理数据从 16 MiB 到 64 KiB；PNG 文件大小不遵循固定比率。

若旧图集含 256 份完全相同的 128×128 内容，只保留一份并让对应面共用它，可保持局部纹理像素。若大量内容独有，则需简化或重绘；不要承诺数学意义的无损。

先统计**纹理内容**，不要将不同 UV 矩形的数量直接当成独有图案数量。精确比较包括 RGBA、尺寸和采样边界；相似图像哈希只用来寻找待审核候选。

## UV 单位

静态图片中：

```text
图片像素 X = UV逻辑坐标 X × 图片宽度 / 逻辑UV宽度
图片像素 Y = UV逻辑坐标 Y × 图片高度 / 逻辑UV高度
```

Generic Model 可使用每张贴图独立的逻辑 UV 尺寸。Bedrock 通常使用项目分辨率。自定义格式以实时能力、每个面的有效贴图和帧尺寸为准，不套用固定 4 倍关系。动画贴图不能把全条带高度当作单帧高度。

旧贴图的区域 A 搬到新区域 B 时：先转换为图片像素，再求 A 内局部坐标，最后映射到 B；转换回目标逻辑 UV 单位。完整区域的重排不能只把绝对坐标除以分辨率比。

分数 UV 的裁剪采用向外取整，并保留面相对裁剪框的偏移。否则改变采样边界后，即使复制了同样像素也可能出现一像素偏差。

## 保持材质尺度

对矩形面分别计算：

```text
d_u = 实际读取的图片像素宽度 / 沿 U 映射的表面长度
d_v = 实际读取的图片像素高度 / 沿 V 映射的表面长度
```

通常 d_u 与 d_v 应接近；同类材质不同部件的纹理尺度也应接近。90/270 度 UV 旋转会交换表面方向。刚体旋转不改变长度，不能用旋转后的世界包围盒代替面尺寸；inflate 和非均匀形变需要考虑实际长度。

共享一个完整纹理块适合尺寸/比例匹配的面。面对不同尺寸，使用材质场中的比例子区域、合适的长条区域，或目标真正支持的平铺。整张纹理的 Repeat 不等于图集子区域可以独立重复。

## 共享与保护

- 完全重复：精确去重，保留方向与色值。
- 同类噪声/材质：人工确认后按材质场共享，选少量变体并统一尺度。
- 纯色：共用带边距的小色块；若其他 PBR 通道含细节，则不属于纯色。
- 文字、眼睛、徽章、透明轮廓、非对称细节：默认独立；确需重绘时按照原语义和风格制作专用小图，再检查模型上的识别效果。
- 独特烘焙阴影：不能仅因为底色相同就合并。

小图的绘制顺序是主色分布、大明暗、材质特征、识别细节、噪点清理。像素风保持有目的的色块与硬边；非像素风保留其原本的色彩过渡，不能统一改成固定数量的颜色。

## 容量和视觉验收

矩形区域带 p 像素边距的占用面积为 (w+2p)×(h+2p)。面积小于图集只是必要条件，还要检查矩形形状、空隙及实际装箱。不要把 mipmap 下的串色检查省略，也不要用扩大 UV 把其他材质读进来。

比较同一相机、光照和姿态下的颜色比例、明暗、材质识别、关键图案、接缝及透明边缘。至少检查正面、侧面、透视；动画可能露出的表面也要检查。像素差不能直接当作风格保留率：随机纹理的位置变了，逐像素差会很大，但材质表达可能仍成立。

尺寸不够时，优先增加真实复用、减少不必要变体和无效噪点，再调整已认可的像素密度。无法保住关键特征时，报告限制或提供较大分辨率，不能把风格改变藏在“压缩成功”后面。
